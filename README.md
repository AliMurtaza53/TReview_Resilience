# Transport Reviews planning package

Status: proposed protocol and initial evidence matrix, 29 October 2026. This is not a completed PRISMA review or a submission-ready manuscript.

Start with PLAN.md, then FIGURES.md and CODEBOOK.md. The matrix workbook and Git-friendly CSV/JSON files distinguish inherited coding, fresh single-pass review extraction and fields awaiting assessment. Existing draft-review outputs remain in literature_revision/v3.

The previous paper's narrow comparison is a seed corpus for a broader review, not a representative sample or a formal search yield. Blank/unassessed fields must not be treated as absent features. Evidence-overlap estimates are intentionally withheld until included-study rosters are transcribed.

GitHub destination: https://github.com/AliMurtaza53/TReview_Resilience. This package is prepared for a dedicated branch and draft pull request. No source PDFs, Zotero database, private local paths or unpublished manuscript are included. upload_manifest.json records the upload allowlist.
